# DLL для подсветки сообщений

Пример DLL с экспортируемой функцией `chat_transform`. Она ожидает текст вида `TYPE: сообщение` и добавляет ANSI-код цвета для известных типов (сейчас настроен цвет `ORANGE`). Если тип не распознан, текст возвращается без изменений. Для сообщений без префикса (например, личка `@user <текст>`) по умолчанию применяется цвет `ORANGE`.

> Сервер ищет **только** символ `chat_transform` (без манглинга имени). Он должен быть объявлен как `extern "C" __attribute__((visibility("default"), used))` на macOS/Linux или с `__declspec(dllexport)` на Windows. Дополнительные функции можно оставлять для своих нужд, но сервер их не вызовет, если не научить его искать новые символы.

## Как собрать
```bash
cmake -S . -B build
cmake --build build --target chat_mods
```

Готовый файл появится в `build/` (`libchat_mods.so` на Linux/macOS или `chat_mods.dll` на Windows). Подайте его серверу через веб-интерфейс или командой `call <имя>` после копирования в папку `dll_files`.

## Как использовать через админ-панель
1. В панели (порт 80) откройте блок «C++ код для сборки DLL».
2. Вставьте код ниже и укажите имя файла **orange** (поле «Название файла»):
```cpp
#include "chat_mods.hpp"

// Базовый пример: все сообщения без префикса будут оранжевыми
extern "C" CHAT_DLL_EXPORT const char* chat_transform(const char* user, const char* text) {
    (void)user;
    static thread_local std::string out;
    out = "\033[38;5;214m";
    out += text ? text : "";
    out += "\033[0m";
    return out.c_str();
}
```
3. Нажмите «Собрать DLL из кода» — файл появится как `orange.dll` в списке.
4. В чате (порт 8080) выполните `call orange` для активации.
5. Отправьте личку `@user текст` — сообщение придёт оранжевым. Для явных префиксов можно писать `ORANGE: текст` или `MD: текст`.

## Формат сообщений
```
ORANGE: текст
```

Можно расширять функцию `apply_chat_modifications` для своих цветов и правил.
